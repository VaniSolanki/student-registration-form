Student Registration Form

A simple student registration form created using HTML. This project is a beginner-friendly web development project designed to practise HTML form elements and input fields.

Features

- Full name input
- Student information fields
- Date input
- Form elements for student registration
- Simple and clean structure

Technologies Used

- HTML5

How to Run

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open "index.html" in your browser.

Learning Outcomes

- Understanding HTML structure
- Practising HTML form elements
- Working with input types
- Learning how to manage and upload projects using Git and GitHub
